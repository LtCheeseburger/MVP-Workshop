# MVP-Workshop 1.0.14

Windows x64 portable release, built November 23, 2026. Extract the ZIP and run MVP-Workshop.exe; no separate .NET installation is required.

- Includes all accumulated browser, installed-mod discovery, texture replacement, Xbox model geometry and uniform UI improvements since 1.0.7.
- Automatically layers an adjacent MVP27-Overhaul.mvpmod as a read-only base. Use Tools → Locate overhaul to select a package and Tools → Build overhaul to write an edited package.
- Preserves school-by-school browsing and the simplified dressed-player workspace, with optional original comparison and selected-texture thumbnails.
- Includes the optional NASCAR source build variant; this download is the MVP-Workshop application.

Validation: Windows x64 publish, six console suites and six packaged desktop checks passed. The full MVP 27 overhaul integration test was not run because its separate package/installation was unavailable. Existing MicroTalkEncoder compiler warnings remain. See VALIDATION.txt in the archive.

Assets: MVP-Workshop-1.0.14-win-x64.zip and its SHA-256 checksum.
